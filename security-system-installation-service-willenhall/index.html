What the work can involve

The installation depends on the system requested, the property and whether equipment is already in place. A useful first step is to describe the areas or entry points you want considered and any existing alarm or camera equipment. We can then discuss the work that may be needed.

  • What it covers: security system installation, including burglar alarm and CCTV-related requirements. Confirm which equipment and tasks are included for your job.
  • Typical timing: there is no standard appointment length for all properties. The system, amount of work and access to the relevant areas can change the time needed. Ask about scheduling after explaining the job.
  • What affects cost: the selected equipment, installation requirements, existing wiring or equipment, and access at the property. Ask for a clear description of the proposed work and costs before agreeing to proceed.

When comparing providers, ask what equipment they plan to install, which parts of the property the proposal covers, and whether existing equipment will be assessed. Check that each provider is quoting for the same requirements, and ask who will explain any limits or follow-up steps.

You may hear a few common terms. A burglar alarm is a system intended to alert people to an alarm condition. CCTV means closed circuit television, or a camera-based system. A security system is a broader term, so ask which devices and functions are included in the setup being discussed.
